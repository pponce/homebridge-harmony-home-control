Connect your hub

Use the LAN addresses of this Homebridge machine and your Harmony hub. Reserve these addresses in your router so they stay the same.

Network ports and separate VLANs

Discovery uses SSDP on UDP 1900. If Harmony and Homebridge are on different VLANs, ordinary mDNS forwarding is insufficient. Use an SSDP relay or the discovery helper in this plugin’s README, and allow your hub to reach the HTTP ports.

For Docker, use host networking. Hue defaults to 18080 to avoid existing web servers; Harmony compatibility with that port needs testing on your hub. Port 80 is configurable if needed.

Your accessories

Find accessories before creating your first mapping.

Accessory control must be enabled in Homebridge (the -I option). If the Homebridge UI’s Accessories page works, this is usually already enabled. Child bridges are discovered automatically. Accessories paired directly to Apple Home are not included.

Dedicated home-control buttons

Each entry becomes a virtual Hue light that Harmony can assign to a home-control button.

A short press sends On; a long press sends Off. Dimming is optional. Harmony supports one Hue bridge: if you already use one, review the pairing instructions before replacing it.

Other remote buttons

Choose a Roku command and the accessory action it should trigger. You assign the physical button in Harmony.

For example: assign a spare Harmony button to Roku Play, then map Play here to an accessory’s On control. One virtual Roku supports several actions.

Home-control buttons · Hue

  1. Expose at least one accessory on the Home-control buttons tab.
  2. In Harmony, add a home-control device and discover Philips Hue.
  3. When Harmony asks for the Hue link button, select Open pairing window below. Pairing stays open for two minutes.
  4. Import the lights. In Harmony’s Remote & Hub settings, open Button Customization → Home Control Buttons and assign them.

If Harmony cannot finish pairing

Try MyHarmony desktop with the remote connected by USB, then Scan for Devices. Mobile pairing varies between Harmony versions. Check network discovery and HTTP access before changing AV settings.

Harmony permits one Hue bridge. Existing Hue assignments may need to be recreated if you replace its current bridge. Hue cloud scenes and color control are not provided.

Other buttons · Roku

  1. In Harmony, scan your network for entertainment devices and add the discovered Roku. Its serial number starts with HHC.
  2. Rename it to Homebridge Controls in Harmony.
  3. Add it to each activity where you want these commands.
  4. Open Activity Control Buttons, pick a physical button, then assign the Roku command shown in your mapping.
  5. Sync your remote, start that activity, and press the button. Check Recent commands below.

The plugin cannot change Harmony’s button assignments. Short and long presses can send different Roku commands when configured in Harmony. Home-control buttons use the Hue interface.
