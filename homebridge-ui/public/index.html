Local network
Network ports & separate VLANs

Discovery uses SSDP on UDP 1900. Across VLANs, use an SSDP relay or the discovery helper in the README, and allow your hub to reach these HTTP ports. Ordinary mDNS forwarding is insufficient.

For Docker, use host networking. Hue defaults to 18080; port 80 is configurable if your Harmony hub requires it. Reserve your devices’ IP addresses in your router.

Optional HTTPS certificate for the web configurator

These files enable HTTPS directly on the configurator webserver. They are not Logitech account certificates.

Leave both fields empty to use local HTTP and open the web configurator with the Open configurator button in these settings. You can inspect the hub and draft changes without a certificate. Also leave them empty when an HTTPS reverse proxy such as Nginx handles the certificate.

Entering a configurator password or Logitech credentials requires HTTPS or a localhost SSH tunnel. Supply a browser-trusted certificate and its private key here only if the plugin itself will serve HTTPS.

Direct website sign-in

Set a separate configurator username and password to open your bookmarked URL directly. Usernames are case-insensitive and use 1–64 letters, numbers, dots, underscores, @ signs or hyphens. Passwords use 8–256 characters. Saving signs out every browser. The password is not saved in Homebridge configuration.

Enable, save settings and restart this child bridge to open the configurator.

Home-control buttons

Hue
  1. Choose Hue or Homebridge devices on the Home control tab.
  2. In Harmony, discover this plugin’s combined Philips Hue bridge. Replace an existing physical Hue bridge connection in Harmony first.
  3. When Harmony asks for the link button, select Open pairing window below.
  4. Import the lights, then assign them under Remote & Hub → Button Customization → Home Control Buttons.

Pairing help & existing Hue setups

The pairing window lasts two minutes. If mobile pairing fails, try MyHarmony desktop with the remote connected over USB, then Scan for Devices.

Harmony supports one Hue bridge. Replacing its existing connection may require recreating Hue button and activity assignments. Physical bridges can stay connected to Apple Home and the Hue app. Scenes and color control are not provided.

Other buttons

Roku
  1. Scan your network in Harmony and add the discovered Roku. Its serial starts with HHC.
  2. Rename it to Homebridge Controls in Harmony.
  3. Add it to each activity where you want these commands.
  4. Under Activity Control Buttons, assign the Roku command shown in your mapping.
  5. Sync the remote, start that activity, and press the button.

Configure short and long presses in Harmony using different commands. Dedicated home-control buttons use the Hue interface.
