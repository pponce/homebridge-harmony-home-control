# Harmony Home Control 0.1.0

Harmony Home Control brings existing Homebridge accessories and devices from multiple physical Hue bridges to Logitech Harmony remotes through one virtual Hue bridge and a virtual Roku.

## Features

- Map dedicated home-control buttons to accessory power and supported brightness controls.
- Map Roku commands to set, toggle, increase, or decrease supported accessory values.
- Combine selected Hue lights, plugs, and groups with Homebridge main- and child-bridge accessories.
- Browse sources by name, search accessories, and test actions from the Homebridge settings UI.
- Use the optional web configurator to inspect Harmony devices and activities, review supported cloud edits, initiate hub sync, and inspect cached IR command data.
- Open the configurator directly with a local login or through the Homebridge settings UI; HTTPS reverse proxies are supported.
- Keep existing Apple Home accessories without publishing duplicate HomeKit accessories.

## Reliability and usability

- Apply supported Hue power and brightness fields even when a request also contains unsupported color fields.
- Show command details, accepted writes, readback results, and rejected or ineffective actions.
- Use accessory information names for separately published Homebridge sources.
- Catch and log failures at HTTP request, background refresh, and shutdown boundaries.
- Continue closing other components when one cleanup operation fails.
- Keep request URLs, payloads, and credentials out of the new error-boundary logs.

## Requirements and limitations

- Homebridge 1.8+ or 2.x and Node.js 22.13 or newer.
- Homebridge accessory targets require accessory-control mode (`-I`); direct physical Hue targets do not.
- Configure the Homebridge LAN address and allowed Harmony hub addresses before starting Hue/Roku services.
- Harmony supports one connected Hue bridge per hub. Replacing an existing Harmony Hue connection requires recreating its affected assignments.
- Direct Hue sources support BSB002 and BSB003 bridges. Hue scenes, color, color temperature, schedules, and timed transitions are not implemented.
- Existing mappings and pairing data are retained when updating. Restart Homebridge or the plugin's child bridge after installation.

## Validation

The runtime changes passed checks on Node.js 22, 24, and 26, including protocol, configuration, error-boundary, and browser workflow tests.
