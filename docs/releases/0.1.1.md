# 0.1.1 — Package metadata and funding

## Changes

- Declare `supports-hap` for the Homebridge/HAP integration. The plugin controls existing accessories through HAP and does not publish additional HomeKit accessories or register Matter accessories.
- Add GitHub Sponsors and PayPal links to the README and GitHub funding configuration.
- Include standard npm funding metadata for supporting development and Homebridge donation-link display after verification.

## Upgrade

Update through the Homebridge plugin manager or install `homebridge-harmony-home-control@0.1.1`. Existing mappings, pairings, and configuration are preserved. This release changes package metadata and documentation only.

## Requirements

Node.js 22.13.0 or later and Homebridge 1.8 or 2.x. Controlling existing Homebridge accessories requires accessory-control mode (`-I`); direct physical Hue control does not require it. No interactive terminal is required for plugin setup or operation.
